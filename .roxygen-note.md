# Roxygen2 Note

After these changes, the documentation (.Rd files in the `man/` directory) should be regenerated using roxygen2.

To regenerate the documentation, run:
```R
devtools::document()
# or
roxygen2::roxygenise()
```

This will create/update:
- `man/get_drug_events.Rd` (new file)
- `man/get_drug_purchases.Rd` (updated with deprecation notice)
- `man/get_first_purchase.Rd` (updated)
- `man/compute_purchase_frequency.Rd` (updated)
- `man/parallel_compute_purchase_frequencies_for_VNRs.Rd` (updated)

The NAMESPACE file has already been manually updated to export `get_drug_events`.
